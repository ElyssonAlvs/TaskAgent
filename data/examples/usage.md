# Examples for TaskAgent usage

## Exemplo 1: Criar Tarefa
```
>>> criar uma tarefa chamada "Estudar Python"
Tarefa criada: Estudar Python (ID: 1)
```

## Exemplo 2: Listar Tarefas
```
>>> listar minhas tarefas
Tarefas (3):
[1] Estudar Python (pending)
[2] Fazer compras (in_progress)
[3] Reunião (done)
```

## Exemplo 3: Buscar Tarefa Específica
```
>>> mostre a tarefa 1
[1] Estudar Python
Status: pending
Descrição: N/A
```

## Exemplo 4: Deletar Tarefa
```
>>> apagar tarefa 3
Tarefa 3 deletada
```

## Exemplo 5: Filtrar por Status
```
>>> mostrar tarefas em progresso
Tarefas (1):
[2] Fazer compras (in_progress)
```
